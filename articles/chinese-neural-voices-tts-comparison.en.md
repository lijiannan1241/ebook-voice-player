      <h2>Real-World Gotchas: When Voices Still "Fail"</h2>
      <ul>
        <li><strong>Rare Chars / Names / Places / Foreign Mix</strong>: Cloud model gaps → reads Pinyin or skips. Fix: Note correct pronunciation in app notes, or submit feedback to Microsoft TTS Team</li>
        <li><strong>Classical Chinese / Literary / Heavy Dialect</strong>: Modern models trained on Modern Mandarin. Classical pauses, particles off. Fix: Use Yunyang/Yunhao, Speed 0.8×, Side-by-Side with Original</li>
        <li><strong>Network Jitter → Voice Stutters / Quality Drop</strong>: Synthesis timeout auto-retries, extreme falls back to low-quality streaming. Fix: Avoid Peak Hours, Wired Net, or Pre-Export MP3 Offline</li>
        <li><strong>Ultra-Long Paragraphs (>5000 Chars) Timeout</strong>: Single synthesis length capped. App Auto-Chunks by Paragraph, Seamless Stitch, Rarely Perceived</li>
      </ul>
