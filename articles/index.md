      <h2>🔧 进阶配置：按人群「一键预设」</h2>

      <details class="faq-item" open>
        <summary>🚌 通勤党预设（点击展开）</summary>
        <div class="faq-answer">
          <ul>
            <li>电脑端：批量导出 MP3 → 22kHz/单声道/128kbps → 按章拆分/裁剪静音/写ID3</li>
            <li>语音：晓晓(中文) / Aria(英文) → 语速 1.1×</li>
            <li>手机端：Smart AudioBook Player(Android) / Apple Books(iOS)</li>
            <li>设置：倍速 1.5×、跳过静音、均衡器「语音增强」、蓝牙耳机映射(单击暂停/双击下章/三击上章)</li>
            <li>周末 30 分钟 → 一周通勤听书量搞定</li>
          </ul>
        </div>
      </details>

      <details class="faq-item">
        <summary>🇬🇧 英语学习预设</summary>
        <div class="faq-answer">
          <ul>
            <li>三模式轮转：泛听 1.2×(Aria) → 精听 0.7× 单句循环(Aria) → 跟读 0.9× 段落循环(Jenny)</li>
            <li>生词流程：听不懂→单句循环→听写→标注笔记→导出 MD/JSON→脚本转 Anki 卡片</li>
            <li>分级书单：A2《Charlotte's Web》→ B1《Animal Farm》→ B2《Sapiens》→ C1《Thinking, Fast and Slow》</li>
            <li>考试专项：真题文本导入 → Davis/Ryan 新闻语音 1.0× → 模考/精听/跟读三合一</li>
          </ul>
        </div>
      </details>

      <details class="faq-item">
        <summary>👴 给长辈/低视力预设</summary>
        <div class="faq-answer">
          <ul>
            <li>视觉：字体 思源黑体 Bold、字号 36px、行距 2.2、段距 1.5em、主题高对比度(黑底黄字)</li>
            <li>语音：晓伊/晓琪(最慢最暖) → 语速 0.7×、高亮色亮黄</li>
            <li>导出 MP3 传老人机/MP3播放器/功能机 → 只教三键：播放/暂停、上章/下章、音量±</li>
            <li>贴纸标记：设备背面贴「中间=播放，上=上章，下=下章，左=-音量，右=+音量」</li>
          </ul>
        </div>
      </details>

      <details class="faq-item">
        <summary>💼 职场办公预设</summary>
        <div class="faq-answer">
          <ul>
            <li>合同审核：云希 1.1× 通读 → 重点条款 0.9× 单句循环 → 书签标记「需改/需确认/风险」→ 导出笔记发同事</li>
            <li>研报速读：批量导入打标签 → 关注标签批量导出 MP3 1.3× → 通勤听 → 书签笔记回工位导出整理</li>
            <li>技术方案：云皓 1.0× + 代码块不读 → 评审会前 1.5× 通听 → 会中章节跳转定位争议点</li>
            <li>会议纪要：晓伊 1.1× + 说话人前缀保留 → 标记「决策/行动项/风险/金句」→ 导出结构化纪要</li>
          </ul>
        </div>
      </details>

      <details class="faq-item">
        <summary>🌙 睡前助眠预设</summary>
        <div class="faq-answer">
          <ul>
            <li>内容：熟悉的散文/随笔/旧书二刷/冥想引导，避免悬疑/技术/情绪激烈</li>
            <li>语音：晓伊/晓琪 → 语速 0.6-0.7×</li>
            <li>定时：睡眠定时器 30-45 分钟 + ✅ 淡出停止(30秒渐弱) + ✅ 进度记忆</li>
            <li>环境：护眼暖黄最低亮度 + 蓝牙耳机/骨传导 + 飞行勿扰模式</li>
            <li>醒来：打开软件/手机 App → 进度自动恢复到停止位置</li>
          </ul>
        </div>
      </details>

      <details class="faq-item">
        <summary>🔒 隐私极客预设</summary>
        <div class="faq-answer">
          <ul>
            <li>断网导入：内部文档/版权书/隐私日记 → 断网环境本地解析、本地书签笔记</li>
            <li>需听时：临时接网合成 → 断网缓存复用 → 或批量导出 MP3 全程离线</li>
            <li>防火墙：仅允许 <code>*.azure.com</code> <code>*.microsoft.com</code> 出站，拒绝其余</li>
            <li>抓包验证：Wireshark 仅见 TTS 请求，无遥测/统计/广告/同步流量</li>
            <li>卸载清理：删 <code>%APPDATA%\EbookVoicePlayer</code> 即干净，无注册表残留</li>
          </ul>
