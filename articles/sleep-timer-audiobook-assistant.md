      <h2>为什么睡前听书需要「专用定时器」？</h2>
      <ul>
        <li><strong>手机自带定时器</strong>：强制切断音频，突兀停止易惊醒；进度不保存，醒来不知听到哪</li>
        <li><strong>播放器睡眠定时</strong>：多数只支持「XX 分钟后停止」，不支持「听完这章停」「听到书签停」</li>
        <li><strong>Windows 电脑播放</strong>：合盖/息屏/锁屏可能停止播放、或继续放到天亮耗电</li>
      </ul>
      <p>Ebook Voice Player 睡眠定时器专为「听书入睡」设计：</p>
      <ol>
        <li><strong>三种停止条件</strong>：⏱ 分钟数（5-120分钟） / 📖 章节数（1-10章） / 🔖 书签位置（听到此书签停）</li>
        <li><strong>淡出停止</strong>：最后 30 秒音量线性衰减至 0，不突兀、不惊醒</li>
        <li><strong>进度精准记忆</strong>：停止瞬间自动保存「书籍+章节+段落+字符偏移」，醒来打开软件/手机导入 MP3 秒级恢复</li>
        <li><strong>跨设备同步</strong>：电脑设定定时 → 导出 MP3 传手机 → 手机播放器同步进度（Smart AudioBook Player 支持）</li>
      </ol>

      <h2>睡眠定时器实操：三步设定，今晚就能用</h2>

      <h3>方式 A：电脑直听（适合床头有笔记本/台式机）</h3>
      <ol>
        <li>打开书 → 调到舒服位置（章节/段落）</li>
        <li>右下角播放器区域 → 点击「月亮图标 🌙 睡眠定时器」</li>
        <li>选择停止条件：
          <ul>
            <li><strong>时长模式</strong>：30 分钟（浅眠入睡）、45 分钟（标准入睡周期）、60 分钟（深度放松）</li>
            <li><strong>章节模式</strong>：1 章（短章小说）、2-3 章（长章非虚构）、「到书末尾」（听完这本书睡）</li>
            <li><strong>书签模式</strong>：预先加个书签「🛌 睡眠点」，定时器选「到书签停」</li>
          </ul>
        </li>
        <li>✅ 勾选「淡出停止（30秒渐弱）」</li>
        <li>点「启动」 → 躺平闭眼 → 听书入睡</li>
      </ol>

      <h3>方式 B：导出 MP3 传手机/老人机（更省电、更稳、不占床头）</h3>
      <ol>
        <li>电脑端：选好书 → 导出音频 → MP3、语速 0.7×、语音 <strong>晓伊（温柔慢速）</strong>/<strong>晓琪（更慢更暖）</strong>、✅ 按章拆分、✅ 裁剪静音、✅ 写 ID3</li>
        <li>传手机 → Smart AudioBook Player / Apple Books / 网易云音乐本地导入</li>
        <li>手机端设置睡眠定时器（Smart AudioBook Player：菜单 → 睡眠定时器 → 30分钟/章节末尾/自定义时间，支持淡出）</li>
        <li>手机飞行模式/勿扰模式 → 蓝牙耳机/枕边音箱 → 听书入睡</li>
      </ol>

      <h2>进阶：把「睡前听书」变成「睡眠仪式」</h2>

      <h3>1. 固定「睡眠书单」，建立条件反射</h3>
      <ul>
        <li>建立 3-5 本固定「睡眠书」：只用于睡前听、不在其他时间听</li>
        <li>大脑形成条件反射：<strong>听这几本书的声音 = 该睡觉了</strong></li>
        <li>推荐类别：<strong>散文随笔 > 熟悉的小说二刷 > 养生/冥想 > 熟悉的英文原版</strong>，避免悬疑、惊悚、硬核技术、情绪激烈内容</li>
      </ul>

      <h3>2. 环境配合：三重「关灯」信号</h3>
      <ol>
        <li><strong>视觉关灯</strong>：电脑/手机开启「护眼模式/深色模式」+ 亮度拉最低 + 蓝光过滤开最大</li>
        <li><strong>听觉关灯</strong>：语速 0.7×、音量 30%-40%、开启淡出、蓝牙耳机/骨传导/枕边小音箱（避免入耳式压迫耳道）</li>
        <li><strong>触觉关灯</strong>：放下手机、盖好被子、调整枕头、深呼吸 3 次 → 点「启动定时器」</li>
      </ol>

      <h3>3. 进度管理：醒来「无缝衔接」</h3>
      <ul>
        <li>电脑端：醒来打开软件 → 书籍列表显示「上次阅读：第 3 章 第 2 段 12:34」→ 点「继续」秒恢复</li>
        <li>手机端：Smart AudioBook Player 自动保存进度，打开 App 直接「继续播放」</li>
        <li>跨设备：电脑听到第 3 章中间 → 导出 MP3 传手机 → 手机导入自动识别章节 → 从第 3 章 12:34 继续（需手动拖进度条到对应位置，或用书签同步）</li>
      </ul>

      <h2>特殊场景解决方案</h2>

      <h3>场景 1：半夜醒来想继续听（不想开手机亮屏）</h3>
      <ul>
        <li>蓝牙耳机双击/三击（Smart AudioBook Player 可映射：「双击=播放/暂停，三击=上一章」）</li>
        <li>或用「语音助手」：Hey Siri / 小爱同学 / Google Assistant → 「继续播放」/「播放上一章」</li>
        <li>实体按键 MP3 播放器/老人机：盲摸按键最可靠</li>
      </ul>

      <h3>场景 2：想听「白噪音/雨声/海浪」而非语音</h3>
      <p>Ebook Voice Player 专注语音朗读。变通：找无版权白噪音文本（如「雨声持续 8 小时」文本）导入 → 语音选晓伊 0.5× → 导出 MP3 → 循环播放。更推荐：专用白噪音 App（Rain Rain, White Noise Generator）配合睡眠定时器。</p>

      <h3>场景 3：两人同床、一人听书一人睡</h3>
      <ul>
        <li>骨传导耳机（Shokz/OpenRun）：不堵耳道、不漏音、侧躺不压耳</li>
        <li>枕边定向音箱（参考：JBL SoundFly / 华为 Sound X 定向声）：声场聚焦枕头区域</li>
        <li>单耳蓝牙耳机（仅戴一只耳）：另一只耳听环境音/伴侣说话</li>
      </ul>

      <h3>场景 4：想记录「睡前灵感/梦境线索」</h3>
      <ul>
        <li>听到触动的句子 → 睡眠定时器未停前 → `Ctrl+Shift+N` 快速加笔记（支持语音输入/手写板）</li>
        <li>醒来导出笔记 → 整理进「睡眠日记」/「灵感收集箱」</li>
        <li>或用手机「语音备忘录」边听边留语音便签（需开飞行模式防打扰）</li>
      </ul>

      <h2>常见问题快答</h2>
      <details class="faq-item">
        <summary>电脑合盖/息屏/锁屏后播放会停吗？</summary>
        <div class="faq-answer"><p>默认不会。Ebook Voice Player 申请了「系统必需」电源请求，合盖/息屏/锁屏下继续播放。如需合盖停止：设置 → 电源 → 「合盖操作」改为「睡眠/休眠」。建议：插电源使用、关闭屏幕即可（Win+L 锁屏最稳）。</p></div>
      </details>
      <details class="faq-item">
        <summary>定时器到点淡出时，能不能「再给我 5 分钟」？</summary>
        <div class="faq-answer"><p>淡出过程中点击播放器区域「展开」→ 点「延长 5 分钟」/「取消定时器」。或键盘快捷键 `Ctrl+Shift+S` 快速延长。手机端同理。</p></div>
      </details>
      <details class="faq-item">
        <summary>醒来发现定时器没停/停早了/进度对不上？</summary>
        <div class="faq-answer"><p>排查：1) 确认定时器确实「启动」了（图标变亮/有倒计时显示）2) 检查电源设置是否导致后台挂起 3) 手机端确认播放器有「后台播放」权限 4) 进度偏差通常<10秒，手动拖拽/书签跳转秒级修正。</p></div>
      </details>
      <details class="faq-item">
        <summary>能不能「每天固定时间自动开始播放+定时停止」？</summary>
        <div class="faq-answer"><p>软件无内置「闹钟播放」。变通：Windows 任务计划程序 → 每天 22:30 运行 <code>ebook-voice-player.exe --play-last --sleep-timer 30</code>（需命令行参数支持，当前版本暂无，可提交功能建议）。现阶段建议：手机端设置闹钟提醒「开听书」、睡眠定时器自动停。</p></div>
      </details>
