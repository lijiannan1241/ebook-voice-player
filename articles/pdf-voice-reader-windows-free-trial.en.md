      <h2>Deep Test: How Ebook Voice Player Handles "Hard" PDFs</h2>

      <h3>1. Two-Column Papers: Auto-Merge Reading Order, Footnotes Inline</h3>
      <p>Import <code>attention_is_all_you_need.pdf</code> (two-col, footnotes everywhere). App detects two-col layout, reflows text "left-col top→bottom, right-col top→bottom". Footnote marker <code>[1]</code> click shows popup; narration can "read footnotes/skip footnotes". Headers/footers/page numbers auto-filtered—no "Page 3" or "arXiv:1706.03762" spoken.</p>

      <h3>2. Scanned Textbooks: Honest "Needs OCR" Prompt, No Garbage</h3>
      <p>Drag scanned <code>Intro_to_Algorithms.pdf</code>. 2-sec parse, yellow banner: <strong>"Pure image PDF detected. Use Adobe Acrobat OCR or online OCR first."</strong> Unlike tools that force OCR and spew garbage.</p>
      <p><strong>Practical Fix</strong>: Scanned → <a href="https://www.adobe.com/acrobat/online/ocr-pdf.html" rel="noopener">Adobe Online OCR</a> (free tier enough) or <code>ocrmypdf</code> CLI batch → Searchable PDF → Import.</p>

      <h3>3. Contracts/Reports: TOC Pages Auto-Skipped, Clause Numbers Keep Hierarchy</h3>
      <p>80-page <code>MSA.pdf</code>. App reads PDF bookmarks/TOC → Chapter tree: <code>Section 1 Definitions → 1.1 Terms → 1.2 Abbreviations</code>. Narration speaks clause numbers (1.1, 1.2, 2.3.1) for cross-ref. Headers "Confidential", footers "Page X" auto-suppressed.</p>

      <h3>4. Technical Docs: Code Blocks "Show Don't Speak", CLI Copyable</h3>
      <p>Kubernetes runbook PDF. Code blocks (YAML, Shell) grey-boxed in view, <strong>auto-skipped in narration</strong>—no <code>kubectl get pods -n kube-system</code> letter-by-letter. Need command explanation? Click "Read Description" above block, hears only natural-language paragraphs.</p>
