      <h2>为什么不推荐在线转换网站？</h2>
      <p>搜“EPUB转MP3”前几页全是上传文件的网站。问题有三：</p>
      <ol>
        <li><strong>隐私风险</strong>：书籍上传云端，版权书、内部资料、个人笔记全裸奔。</li>
        <li><strong>功能受限</strong>：免费版限文件大小、限时长、加水印、不分章节、语音只能选一种。</li>
        <li><strong>不稳定</strong>：排队久、转换失败、下载链接失效、广告弹窗满屏。</li>
      </ol>
      <p>本地软件<strong>Ebook Voice Player</strong>（微软商店免费试用）解决这三点：书籍不出电脑、章节自动拆分、语音语速随选、导出MP3无水印。</p>

      <h2>准备工作（5分钟搞定）</h2>
      <ul>
        <li>Windows 10/11 电脑一台</li>
        <li>微软商店安装 <strong>Ebook Voice Player</strong>（搜名字或 <a href="https://apps.microsoft.com/store/detail/9NLHLN1SJNBR?cid=DevShareMCLPCS" rel="noopener">直链</a>）</li>
        <li>待转换的 EPUB 文件（带目录结构的效果最好）</li>
        <li>手机 + 数据线或微信/Telegram/网盘传输</li>
      </ul>

      <h2>四步走：EPUB → 分章节MP3 → 手机</h2>

      <h3>第1步：导入书籍，确认章节</h3>
      <ol>
        <li>打开软件 → 左上角“文件” → “打开书籍” → 选中 .epub 文件</li>
        <li>右侧面板自动弹出<strong>章节列表</strong>，核对章节标题、顺序是否正确</li>
        <li>若目录识别有误（极少见），可右键章节“重命名”或“合并/拆分”</li>
      </ol>
      <p><strong>小技巧</strong>：EPUB若是多文件合集（如文集），软件会按<code>spine</code>顺序自动串联，章节树会显示完整层级。</p>

      <h3>第2步：选语音、调语速、试听</h3>
      <ul>
        <li>右侧“语音”面板 → 语言选“中文” → 推荐<strong>晓晓（通用自然）</strong>或<strong>云希（广播感强）</strong></li>
        <li>语速滑块默认 1.0×，建议：<strong>小说 1.1-1.2×</strong>、<strong>专业书 0.9-1.0×</strong>、<strong>英语原版 0.8×</strong></li>
        <li>点任意章节“试听” 10 秒，确认语调、停顿、多音字无误</li>
      </ul>

      <h3>第3步：导出 MP3（核心步骤）</h3>
      <ol>
        <li>顶部菜单“文件” → “导出音频” → 选择导出范围：<strong>全书 / 选中章节 / 当前章节</strong></li>
        <li>输出设置：
          <ul>
            <li>格式：MP3（通用兼容性最好）</li>
            <li>采样率：22.05 kHz（语音足够，文件小）或 44.1 kHz（追求音质）</li>
            <li>✅ 勾选“按章节拆分文件” → 每章一个 .mp3，手机播放器自动识别章节</li>
            <li>✅ 勾选“裁剪静音” → 去除段落间长停顿，压缩体积约 15%</li>
            <li>✅ 勾选“写入 ID3 标签” → 标题=章节名，专辑=书名，画面=封面图</li>
          </ul>
        </li>
        <li>选保存文件夹 → “开始导出” → 进度条跑完即可</li>
      </ol>
      <p><strong>实测数据</strong>：30万字小说，按章导出约 45 个 MP3，总耗时 8 分钟（含网络合成），总体积约 420 MB（22kHz），手机存得下。</p>

      <h3>第4步：传手机，选播放器</h3>
      <p><strong>传输方式</strong>：数据线拷入 Music 文件夹 / 微信文件传输助手 / Telegram Saved Messages / 网盘同步盘。</p>
      <p><strong>推荐播放器（支持章节跳转、倍速、定时、书签）</strong>：</p>
      <ul>
        <li>iOS：<strong>Apple Books</strong>（原生识别章节）、<strong>Voice Audiobook Player</strong></li>
        <li>Android：<strong>Smart AudioBook Player</strong>（神器，支持章节、倍速、睡眠定时、书签、变调）、<strong>Listen Audiobook Player</strong></li>
      </ul>

      <h2>批量处理：一次搞定整个书架</h2>
      <ol>
        <li>软件左下角“添加文件夹” → 选中存 EPUB 的根目录</li>
        <li>书库列表出现所有书籍，逐本确认章节无误</li>
        <li>全选（Ctrl+A） → 右键“批量导出音频” → 统一设置输出参数</li>
        <li>建议：按“书名/章节.mp3”命名规则，输出到统一文件夹，手机端按文件夹分类</li>
      </ol>
      <p>实测：20 本小说（共 600 万字）批量导出约 35 分钟，全程无需守着。</p>

      <h2>常见坑 & 解法</h2>
      <details class="faq-item">
        <summary>导出的 MP3 章节顺序乱了？</summary>
        <div class="faq-answer"><p>检查 EPUB 内部 <code>spine</code> 顺序。软件按 spine 顺序导出，若源文件 spine 乱序，需用 Calibre 整理后再导入。</p></div>
      </details>
      <details class="faq-item">
        <summary>导出卡住/报错“网络错误”？</summary>
        <div class="faq-answer"><p>合成调用微软 Edge TTS 云端服务，需稳定联网。建议：分批导出（每次 5-10 章）、避开晚高峰、或改用有线网络。</p></div>
      </details>
      <details class="faq-item">
        <summary>手机播放器不显示章节/封面？</summary>
        <div class="faq-answer"><p>确认导出时勾选了“写入 ID3 标签”且“按章节拆分”。Android 用 Smart AudioBook Player 扫描文件夹即可识别章节树。</p></div>
      </details>
      <details class="faq-item">
        <summary>有声书太大，手机存不下？</summary>
        <div class="faq-answer"><p>导出设置选 22.05 kHz、单声道，30 万字约 140 MB。或只导出近期要听的章节，听完删了再导下一批。</p></div>
      </details>

        <li>装 Ebook Voice Player → 导入 EPUB → 确认章节</li>
        <li>选中文语音（晓晓/云希） → 调语速 → 试听</li>
        <li>勾选“按章拆分、裁剪静音、写ID3” → 导出 MP3</li>
        <li>传手机 → 用 Smart AudioBook Player / Apple Books 听</li>
