      <h2>三种英语训练模式：一本书、三套参数</h2>

      <h3>模式 A：泛听 / 通勤磨耳朵（语速 1.1-1.3×）</h3>
      <ol>
        <li>语音：Aria / Guy / Sonia（标准播音腔）</li>
        <li>语速：1.1× 起步，适应后推到 1.2-1.3×</li>
        <li>导出：全书按章导出 MP3，手机 Smart AudioBook Player 倍速播放</li>
        <li>目标：建立语感、积累词汇语境、训练听力耐力</li>
      </ol>

      <h3>模式 B：精听 / 句句过（语速 0.6-0.8× + 单句循环）</h3>
      <ol>
        <li>语音：Aria / Jenny（清晰度最高）</li>
        <li>语速：0.7×（慢到能听清每个音素连读、弱读、失爆）</li>
        <li>操作：软件段落高亮跟随 → 听不懂的句子「单句循环」（右键/快捷键） → 听写/影子跟读</li>
        <li>生词：选中生词 → 右键“查词/加笔记” → 导出笔记含上下文 → 导入 Anki/Notion</li>
        <li>目标：攻克连读弱读、语法结构、生词语境、发音模仿</li>
      </ol>

      <h3>模式 C：跟读 / 影子跟读（语速 0.9-1.0× + 段落循环）</h3>
      <ol>
        <li>语音：Jenny / Jane（自然亲和、有情感起伏）</li>
        <li>语速：0.9×（留出开口跟读的时间窗）</li>
        <li>操作：播放一句 → 暂停 → 复述/跟读 → 对比录音（手机录音备忘录）</li>
        <li>进阶：开启“段落循环”，同一段跟读 3-5 遍直到流利</li>
        <li>目标：语流流利度、语调语感、肌肉记忆、口语输出</li>
      </ol>

      <h2>常见问题快答</h2>
      <details class="faq-item">
        <summary>英语专有名词/人名/地名读音不准？</summary>
        <div class="faq-answer"><p>微软 TTS 对常见专有名词覆盖率高。极少数生僻专有名词会按拼音规则读。解决：笔记里标注正确读音、或用 Forvo/YouGlish 核对、或提交反馈给微软 TTS 团队持续改进。</p></div>
      </details>
      <details class="faq-item">
        <summary>对白密集的小说（如 Harry Potter）怎么区分角色？</summary>
        <div class="faq-answer"><p>单语音无法变声。建议：导出 MP3 后用 Au/Audacity 给不同角色加简单音高偏移（+3/-3 半音），或直接接受单人朗读，配合原文引号标识角色。</p></div>
      </details>
      <details class="faq-item">
        <summary>能不能导出「双语对照」音频（中英交替）？</summary>
        <div class="faq-answer"><p>软件不直接支持。变通：准备中英对照 EPUB（左右对照版）→ 导出时语音选中英混合（中文段用晓晓、英文段用 Aria）→ 需手动在文本里插入语言标记，较麻烦。建议：分别导出中英版，播放器建两个播放列表对照听。</p></div>
      </details>
      <details class="faq-item">
        <summary>导出的 MP3 能不能直接上传到 Anki 做听力卡片？</summary>
        <div class="faq-answer"><p>能。Anki 卡片模板里用 <code>[sound:Chapter_03.mp3]</code> 引用。配合 AwesomeTTS 插件可批量导入。建议：按句切分音频（用 ffmpeg 按静音切分）做单句听力卡，效果最好。</p></div>
      </details>
