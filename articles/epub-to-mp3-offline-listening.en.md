      <h2>Why Avoid Online EPUB-to-MP3 Converters?</h2>
      <p>Search "EPUB to MP3" and the top results are all upload-to-cloud sites. Three problems:</p>
      <ol>
        <li><strong>Privacy risk</strong>: Books uploaded to cloud—copyrighted works, internal docs, personal notes exposed.</li>
        <li><strong>Feature limits</strong>: Free tiers cap file size, duration, add watermarks, no chapter split, single voice only.</li>
        <li><strong>Unreliable</strong>: Queue times, conversion failures, dead download links, ad walls.</li>
      </ol>
      <p>Local software <strong>Ebook Voice Player</strong> (Microsoft Store, free trial) solves all three: books never leave PC, chapters auto-split, voice/speed per book, MP3 export watermark-free.</p>

      <h2>Prerequisites (5-Minute Setup)</h2>
      <ul>
        <li>Windows 10/11 PC</li>
        <li>Install <strong>Ebook Voice Player</strong> from Microsoft Store (search name or <a href="https://apps.microsoft.com/detail/9nlhln1sjnbr?cid=DevShareMCLPCS&hl=zh-CN&gl=CN" rel="noopener">direct link</a>)</li>
        <li>EPUB files to convert (with TOC structure works best)</li>
        <li>Phone + USB cable / WeChat / Telegram / cloud sync for transfer</li>
      </ul>

      <h2>Four Steps: EPUB → Chapter-Split MP3 → Phone</h2>

      <h3>Step 1: Import Book, Verify Chapters</h3>
      <ol>
        <li>Open app → File → Open Book → Select .epub</li>
        <li>Right panel auto-shows <strong>chapter list</strong>, verify titles/order</li>
        <li>If TOC misread (rare), right-click chapter "Rename" or "Merge/Split"</li>
      </ol>
      <p><strong>Pro tip</strong>: Multi-file EPUB anthologies auto-concatenate by <code>spine</code> order; chapter tree shows full hierarchy.</p>

      <h3>Step 2: Pick Voice, Adjust Speed, Test</h3>
      <ul>
        <li>Right "Voice" panel → Language: Chinese → Recommended <strong>Xiaoxiao (natural)</strong> or <strong>Yunxi (broadcast)</strong></li>
        <li>Speed slider defaults 1.0×. Suggestions: <strong>Novels 1.1-1.2×</strong>, <strong>Non-fiction 0.9-1.0×</strong>, <strong>English originals 0.8×</strong></li>
        <li>Click any chapter "Preview" for 10 sec, confirm prosody, pauses, polyphones</li>
      </ul>

      <h3>Step 3: Export MP3 (Core Step)</h3>
      <ol>
        <li>File → Export Audio → Range: <strong>Full Book / Selected Chapters / Current Chapter</strong></li>
        <li>Output settings:
          <ul>
            <li>Format: MP3 (universal compatibility)</li>
            <li>Sample rate: 22.05 kHz (speech quality, smaller) or 44.1 kHz (audiophile)</li>
            <li>✅ <strong>Split by Chapter</strong> → One .mp3 per chapter, mobile players auto-detect chapters</li>
            <li>✅ <strong>Trim Silence</strong> → Removes inter-paragraph pauses, ~15% size reduction</li>
            <li>✅ <strong>Write ID3 Tags</strong> → Title=Chapter, Album=Book, Artwork=Cover</li>
          </ul>
        </li>
        <li>Choose output folder → Start Export → Done when progress bar completes</li>
      </ol>
      <p><strong>Real-World Numbers</strong>: 300k-word novel → ~45 chapter MP3s, 8 min total (incl. cloud synthesis), ~420 MB at 22 kHz. Fits on phone easily.</p>

      <h3>Step 4: Transfer to Phone, Pick Player</h3>
      <p><strong>Transfer</strong>: USB to Music folder / WeChat File Transfer / Telegram Saved Messages / Cloud sync folder.</p>
      <p><strong>Recommended Players (Chapter Jump, Speed, Timer, Bookmarks)</strong>:</p>
      <ul>
        <li>iOS: <strong>Apple Books</strong> (native chapter support), <strong>Voice Audiobook Player</strong></li>
        <li>Android: <strong>Smart AudioBook Player</strong> (gold standard: chapters, speed, sleep timer, bookmarks, pitch), <strong>Listen Audiobook Player</strong></li>
      </ul>

      <h2>Advanced: Fix "Unnatural" Sound with Three Parameters</h2>
      <table class="facts-table">
        <caption>Voice Tuning Cheatsheet</caption>
        <thead>
          <tr><th>Issue</th><th>Adjust</th><th>Suggested Value</th><th>Use Case</th></tr>
        </thead>
        <tbody>
          <tr><td>Too fast to follow</td><td>Speed</td><td>0.85-0.95×</td><td>Textbooks, English originals, elderly</td></tr>
          <tr><td>Too slow, drowsy</td><td>Speed</td><td>1.15-1.3×</td><td>Web novels, news, re-reads</td></tr>
          <tr><td>Pauses too short, breathless</td><td>Speed down slightly + Disable silence trim</td><td>1.0× + No trim</td><td>Poetry, essays, dialogue-heavy</td></tr>
          <tr><td>Names/places mispronounced</td><td>Switch Voice</td><td>Yunxi / Yunyang</td><td>Fantasy, translated names, dialect words</td></tr>
          <tr><td>Numbers/symbols spelled out</td><td>Cloud-side normalization, not locally fixable</td><td>—</td><td>Technical docs, code, formulas</td></tr>
        </tbody>
      </table>

      <h2>Batch Processing: Entire Bookshelf in One Go</h2>
      <ol>
        <li>App bottom-left "Add Folder" → Select root folder with EPUBs</li>
        <li>Library lists all books. Quick verify each chapter tree.</li>
        <li>Select All (Ctrl+A) → Right-click "Batch Export Audio" → Unified settings</li>
        <li>Suggest: "BookTitle/Chapter.mp3" naming, single output folder, phone scans by folder</li>
      </ol>
      <p>Tested: 20 novels (6M words) batch exported in ~35 min, zero babysitting.</p>

      <h2>Common Pitfalls & Fixes</h2>
      <details class="faq-item">
        <summary>Exported MP3 chapter order wrong?</summary>
        <div class="faq-answer"><p>Check EPUB internal <code>spine</code> order. App exports by spine. Fix with Calibre: Edit Metadata → Reorder Chapters → Save → Re-import.</p></div>
      </details>
      <details class="faq-item">
        <summary>Export hangs / "Network Error"?</summary>
        <div class="faq-answer"><p>Synthesis calls Microsoft Edge TTS cloud. Need stable connection. Batch smaller (5-10 chapters), avoid evening peak, or use wired Ethernet.</p></div>
      </details>
      <details class="faq-item">
        <summary>Mobile player doesn't show chapters/cover?</summary>
        <div class="faq-answer"><p>Confirm export had "Write ID3" + "Split by Chapter" checked. Smart AudioBook Player: Settings → "Read Chapters from File Tags" ON. Apple Books: Drag folder into app or open via Files app.</p></div>
      </details>
      <details class="faq-item">
        <summary>Audiobooks too large for phone storage?</summary>
        <div class="faq-answer"><p>Export at 22.05 kHz mono: 300k words ≈ 140 MB. Or export only next-up chapters, delete after listening, re-export next batch.</p></div>
      </details>
