你大概经历过这样的时刻：找到一本想看的小说，却是 TXT；想听，系统朗读器只有两个机械音；换到在线 TTS，复制粘贴、字数限制、广告、断句错误；最后只能放弃。

**Ebook Voice Player 不是一个在线 TTS 网页，也不是一个 4 GB 的离线模型。** 它是一个 Windows 桌面阅读器：把书打开、把章节分好、把声音选好，然后让你从任意一段开始听。

## 8 个值得下载的理由

### 1. 229 种声音，不是一个机器人读到底

覆盖 56 种语言与地区口音、75 个地区。中文不只普通话：粤语、东北话、陕西话、台湾腔都有明确标注；英文覆盖美/英/澳/加/印等口音；还有日语、韩语、法语、德语、西班牙语、俄语、阿拉伯语、泰语、越南语等。

语音列表支持搜索，选中即可试听；播放中切换声音，当前段落播完后新声音自动接上。

### 2. 四种主流格式，外加编码自动识别

支持 **TXT、DOCX、PDF、EPUB**，并兼容 HTML。TXT 会自动尝试 UTF-8、GBK、GB2312、GB18030、Big5、UTF-16、Shift-JIS、EUC-JP 等编码，减少“打开全是乱码”的尴尬。

> 扫描版 PDF 没有文字层，需要先用 OCR 工具处理；这是所有文本朗读器的共同边界。

### 3. 自动分章，也能从任意一段开始

中文“第 X 章/卷/篇/话/节/集”、英文 Chapter/Part/Section/Volume 都能识别；二级标题不会重复成章。你可以：

- 用章节下拉框直接跳章；
- 点击正文任意段落，从该段开始朗读；
- 用上一段/下一段按钮微调；
- 下次打开自动恢复上次位置。

### 4. 真正的“边看边听”

朗读时当前段落高亮，阅读区自动跟随滚动；状态栏显示进度百分比、当前段/总段数，并根据已朗读速度估算剩余时间。切章时朗读位置同步切换，不需要手动找。

### 5. 为长文准备的工程细节

- 后台并行合成，默认 3 个并发，边生成边播放；
- 以 `文本 + 声音 + 语速` 生成 SHA-256 缓存键，重复段落秒开；
- 阅读区按 32 段一批分帧渲染，并在构建期间控制 GC，万段级长文不会一次性卡死界面；
- 针对 Windows/SDL2 音频结束事件不稳定的问题加入播放看门狗，避免“第一段播完就停住”。

### 6. 术语替换，专治人名、地名、功法名

在书所在目录放一个 `名词转换.txt`，每行“原词 + Tab + 替换词”即可。替换按最长词优先，`索菲莉亚` 不会被 `索菲` 抢先替换；把替换值写成 `（空白符）` 可以删除不需要读出的符号。

```text
# 原词<Tab>替换词
索菲	索菲娅
萧炎	萧焱
系统	金手指
```

这个文件只影响朗读，不改动原书；同一目录下的书自动共用一套术语表。

### 7. 阅读工作流，不止“播放”

书签、段落笔记、全文搜索、F3 查找下一个、睡眠定时、字号调整、行距调整、深色/浅色主题、全屏阅读、最近文件、阅读统计、中英文界面、键盘快捷键——一个窗口里完成“找书、读、听、记、导出”。

### 8. 整本导出 MP3，通勤时离线听

可以把当前书按段落导出为编号 MP3 文件，文件名从 `段落_0001.mp3` 开始排好，方便拷到手机、MP3 播放器或车载 U 盘。已合成音频有本地缓存，也可以随时清理缓存释放空间。

## 3 分钟上手

1. 从 [Microsoft Store](https://apps.microsoft.com/store/detail/9NLHLN1SJNBR?cid=DevShareMCLPCS) 安装并打开。
2. `文件 → 打开文件` 选择一本书；或 `文件 → 打开目录书库` 把整个文件夹当一本书。
3. 在右侧语音面板搜索/试听，选中喜欢的声音。
4. 点击正文任意段落，或按底部 `▶` 开始朗读；`Space` 暂停/继续。
5. 需要离线听时，用 `工具 → 导出为音频文件` 导出 MP3。

## 技术栈

- **界面：** Python 3 + Kivy 2.3，桌面/窄屏自适应布局
- **语音：** edge-tts（Microsoft Edge 神经语音），asyncio 并行合成
- **文档解析：** PyMuPDF / pdfplumber、python-docx、EbookLib、BeautifulSoup
- **缓存：** SHA-256 内容寻址，MP3 有效性校验
- **性能：** 分帧渲染、GC 控制、播放看门狗、后台线程 + 信号量
- **测试：** pytest 覆盖 reader、TTS 引擎、语音管理、界面组件与响应式布局
- **分发：** MSIX 打包，Windows 10 版本 17763 及以上 / Windows 11，x64

## 隐私与边界

- 书籍文件在本地打开，不上传到任何自建内容服务器；本产品没有账号体系。
- 朗读文本会发送到 Microsoft Edge TTS 服务进行语音合成。
- 合成结果缓存在本机，可在 `工具 → 清理音频缓存` 中删除。
- 请只朗读你有权使用的文件；本产品不提供 DRM 破解或版权内容下载。
