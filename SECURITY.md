# Security Policy

## Supported versions

Ebook Voice Player is distributed as a signed MSIX package through the Microsoft Store. Only the latest published version receives security updates. Keep the app updated via the Microsoft Store to stay protected.

| Version | Supported |
|---|---|
| Latest Store release | ✅ |
| Older releases | ❌ |

## Reporting a vulnerability

**Please do not report security issues in public GitHub Issues**, especially if the details could help an attacker.

Instead, report privately through one of these channels:

1. **Microsoft Store listing** → "Contact developer" on the [app's Store page](https://apps.microsoft.com/detail/9nlhln1sjnbr?cid=DevShareMCLPCS&hl=zh-CN&gl=CN).
2. If you must use GitHub, open a normal Issue saying only *"Security issue — please contact me privately"* and include your preferred contact method; do not paste exploit details.

Please include:
- Affected version and Windows version
- Steps to reproduce
- Potential impact
- Any suggested fix (optional)

We aim to acknowledge reports within **7 days** and provide an update on remediation within **30 days**, depending on complexity.

## Scope

- The Windows application (MSIX, Store distribution)
- This repository's website and guide content (e.g. injected scripts, malicious links)

Out of scope: the Microsoft Edge online text-to-speech service, Microsoft Store infrastructure, and third-party sites linked from our guides.

## Acknowledgments

Responsible reporters will be credited in the release notes if they wish.
