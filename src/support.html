Support

Short answers to the problems that come up most often. For app-specific issues, the Microsoft Store product page is the fastest route to the publisher.

Getting started

  1. Install {{APP_NAME}} from the Microsoft Store and open it.
  2. Choose File → Open book and select a TXT, DOCX, PDF, EPUB or HTML file.
  3. Pick a voice in the voice panel and set the speed you like.
  4. Press play, or click any paragraph to start reading from there.

System requirements

  • Windows 10 version 1809 (build 17763) or later, or Windows 11
  • x64 processor
  • An internet connection for speech synthesis
  • An audio output device

The app is installed as a signed MSIX package. Updates are delivered through the Microsoft Store.

No sound when I press play

  • Check that the correct output device is selected in Windows and that the volume is not muted.
  • Confirm the computer is online. Speech is generated by an online service, so playback stops without a connection.
  • Try a different voice. If one voice fails and another works, the issue is with that voice on the service side.
  • Close and reopen the app, then try the same paragraph again.

A book will not open or looks empty

  • DRM-protected EPUB and PDF files cannot be opened. Use a DRM-free copy.
  • A PDF that contains only scanned page images has no text layer to read. Ebook Voice Player does not perform OCR.
  • Very large books can take a few seconds to parse. Wait for the chapter list to appear before pressing play.
  • If the layout looks wrong, try re-opening the file; if it persists, the file structure may be unusual.

Where are exported MP3 files saved?

Exports are written to the folder you choose in the export dialog. If you cannot find a file, search for the book title in File Explorer or export again and note the destination folder.

How do I change the interface language?

Open the Language menu and choose English or 简体中文. The change applies immediately and is remembered for the next session.

How do I remove my data?

Books are not copied into the app; they stay wherever you opened them. Settings, bookmarks, notes and the speech cache are stored in your Windows user profile. Uninstalling the app removes the program; to remove the remaining data, delete the app's data folder under %APPDATA% after uninstalling.
