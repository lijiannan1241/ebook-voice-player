如何使用

三步，从书架到声音

  1. 打开一本书

    选择 TXT、DOCX、PDF、EPUB 或 HTML 文件，也可以添加整个文件夹。程序在本地解析并整理章节。

  2. 选择语音

    按语言和地区浏览，试听几种声音，再调整语速。下次打开会自动沿用。

  3. 按下播放

    从头开始，或点击任意段落。跟着高亮阅读、加书签，或导出音频稍后听。

常见问题

读者常问的问题

简短直接的回答。更多内容见支持页面。

Ebook Voice Player 是什么？

Ebook Voice Player 是一款 Windows 桌面电子书朗读器。打开 TXT、DOCX、PDF、EPUB 或 HTML 文件，选择语音后，程序会在保留文字页面的同时朗读内容，并高亮正在朗读的段落。

支持哪些电子书格式？

支持 TXT、DOCX、PDF、EPUB 和 HTML。文件结构包含章节时会自动识别，也可以从任意段落开始朗读。

需要联网吗？

打开和排版书籍在本地完成，但语音合成使用在线神经网络语音服务，因此生成新的语音时需要联网。导出的 MP3 文件可以离线播放。

有多少种语音和语言？

目前提供 300 多种神经网络语音，覆盖 70 多种语言和 140 多个地区口音。具体列表取决于在线语音服务，应用会自动更新。

可以导出 MP3 吗？

可以。你可以把选定章节或整本书导出为 MP3，复制到手机、MP3 播放器或其他设备离线收听。

系统要求是什么？

Windows 10 版本 1809（内部版本 17763）或更高版本，或 Windows 11，x64 处理器。应用通过 Microsoft Store 以签名 MSIX 包分发，语音合成需要联网。
